# DataCircles CRM – Mobile App

Standalone Expo app (separate from `frontend/` and `backend/`). Phase 1 wraps the
website's mobile UI in a WebView; screens will be replaced with native ones later.

- `npm install`, then `npx expo start`
- Web URL is set by `EXPO_PUBLIC_WEB_URL` in `.env` (see `.env.example`)
- Reference app: `C:\ROHIT\DataCircles\YETZU - Mobile App\yetzu-app`
